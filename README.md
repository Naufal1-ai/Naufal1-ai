### 💻 About Me

- 🎓 Mahasiswa D4 **Teknologi Rekayasa Perangkat Lunak** di **Politeknik Negeri Padang**.
- 🤖 Aktif di **UKM Robotik** kampus, fokus membangun software untuk sistem robotika dan **computer vision**.
- 🧠 Saat ini mengerjakan sistem deteksi bola real-time dengan **YOLOv8 + Kalman Filter** di **Jetson Nano** untuk robot **KRSBI Humanoid**.
- 🌐 Di sisi lain, saya membuat aplikasi web dengan **PHP/Laravel** untuk tugas dan proyek kuliah.
- 🛠️ Hobi: merakit robot, microcontroller, dan 3D modeling.
